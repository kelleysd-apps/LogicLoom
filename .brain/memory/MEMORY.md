(`.logic-loom/config/memory-backend.conf`). In-tree and versioned so lessons
travel with the code rather than living on one machine; stripped at template
release, so no adopter receives them.

the repository's, and this repo is public. `feedback-cto-level-comms` — how the
maintainer wants to be reported to — lives in `~/.claude/CLAUDE.md` and in the
personal vault at `_agent/memory/shared/cto-level-comms.md`, which is where the
project CLAUDE.md's own harness-vs-user boundary says it belongs.
